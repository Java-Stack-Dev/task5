# Task 5 – Exploratory Data Analysis (EDA) on Titanic Dataset

## Task Goal
To explore the Titanic dataset using Python and find patterns that help understand who survived and why.

## Files in This Repo
- `Task5.ipynb` – Jupyter notebook with code and charts
- `train (1).csv` – Dataset used
- `Task5 visual.pdf` – Notebook saved as PDF
- `README.md` – Task details (this file)

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Seaborn
- Matplotlib

##  What I Did
- Loaded and cleaned the dataset
- Checked for missing values and fixed them
- Plotted charts (histograms, countplots, heatmap, pairplot)
- Found relationships between features and survival
- Wrote short notes on each chart

## Key Insights
- Women and 1st class passengers had better chances of surviving
- People who paid more fare mostly survived
- Most passengers were between 20 and 40 years old
- Pclass and Fare affected survival the most
